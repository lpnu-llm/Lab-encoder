# Лабораторна: завершальні шари — residual-зв'язки, нормалізація та Dropout

Продовження `lab-attention` та `lab-positional-encoding`: пояснюємо залишковий
зв'язок, реалізуємо forward і backward, досліджуємо вплив глибини на градієнти.
Далі порівнюємо BatchNorm з LayerNorm, реалізуємо LayerNorm і RMSNorm,
готуємо каркас двох residual-гілок encoder та додаємо Dropout.

Відкрийте [lab_encoder.ipynb](lab_encoder.ipynb) у Jupyter або VS Code.
Заповнюйте `...` та виконуйте комірки по черзі. Альтернатива — редагувати
[lab_encoder.py](lab_encoder.py) і запускати `python3 lab_encoder.py`.
Незавершена вправа зупиняє виконання на своїй перевірці, як у попередніх роботах.

Потрібен Python 3.10+. Основна частина та графіки не потребують сторонніх
бібліотек. Для додаткового порівняння з autograd встановіть `torch`:
`python3 -m pip install torch`.

Порядок роботи:

1. Додавання входу до навчуваної поправки.
2. Правило ланцюга й ручний backward одного блока.
3. Backpropagation через мережу та чисельна перевірка похідних.
4. Зникнення і вибух градієнтів при 1–1000 шарах, включно з residual.
5. Нормалізація активацій; BatchNorm і залежність від складу батчу.
6. LayerNorm: статистики одного токена, epsilon та навчувані gamma/beta.
   RMSNorm: середній квадрат без центрування; порівняння результатів і приклад Gemma 3.
7. Дві residual-гілки pre-norm encoder та відмінність від post-norm.
8. Inverted Dropout: випадкові маски, масштабування, training/evaluation і backward.
9. Поєднання LayerNorm, Dropout та residual-гілок у pre-norm encoder.

Після експериментів із глибиною є два необов'язкові відступи без нумерації:
інтуїтивний зв'язок ResNet із Neural ODE через маленькі залишкові кроки
та перевірка ручних градієнтів у PyTorch. Їх можна пропустити;
наступні вправи від них не залежать.
