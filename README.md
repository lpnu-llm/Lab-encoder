# Лабораторна: Transformer encoder

Продовження `lab-attention` та `lab-positional-encoding`: пояснюємо залишковий
зв'язок, реалізуємо forward і backward, досліджуємо вплив глибини на градієнти
та готуємо каркас двох residual-гілок encoder.

Відкрийте [lab_encoder.ipynb](lab_encoder.ipynb) у Jupyter або VS Code.
Заповнюйте `...` та виконуйте комірки по черзі. Альтернатива — редагувати
[lab_encoder.py](lab_encoder.py) і запускати `python3 lab_encoder.py`.
Незавершена вправа зупиняє виконання на своїй перевірці, як у попередніх роботах.

Потрібен Python 3.10+. Основна частина та графіки не потребують сторонніх
бібліотек. Для додаткового порівняння з autograd встановіть `torch`:
`python3 -m pip install torch`.

Порядок роботи:

1. Додавання входу до навчуваної поправки.
2. Правило ланцюга й ручний backward одного блока.
3. Backpropagation через мережу та чисельна перевірка похідних.
4. Зникнення і вибух градієнтів при 1–1000 шарах, включно з residual.
5. Границя нескінченної глибини через крок `T/N` і метод Ейлера.
6. Дві residual-гілки pre-norm encoder та відмінність від post-norm.
7. Необов'язкова перевірка ручних градієнтів у PyTorch.

«Нескінченна глибина» тут означає математичну границю сімейства скінченних
мереж за фіксованого часу, а не обіцянку необмеженої глибини без витрат.

Для підтримки матеріалів: `make all` оновлює SVG і notebook із Python-джерела;
`make check` перевіряє синтаксис, відтворюваність і всі вправи на еталонних
підстановках, не заповнюючи студентський файл.
